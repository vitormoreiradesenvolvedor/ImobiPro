# Procedência das fotos de imóveis

As imagens da massa de demonstração (vídeo, slides e capturas) são fotografias
reais obtidas pela API do Openverse, filtradas por licença **CC0** ou **domínio
público**, o que permite uso comercial sem atribuição obrigatória. A tabela
existe mesmo assim: saber a origem de cada arquivo é o mínimo antes de publicar
material comercial.

Reprodução: `python3 docs/comercial/fonte/baixar-fotos.py <pasta>` refaz o
download e o recorte em 3:2.
