# Fotos da massa de demonstração

Fotografias reais sob licença CC0 ou domínio público, obtidas pela API do
Openverse. A procedência arquivo a arquivo está em
`docs/comercial/creditos-imagens.md`, e o download pode ser refeito com
`python3 docs/comercial/fonte/baixar-fotos.py <pasta>`.

O `semear_operacao` distribui cinco ambientes por imóvel (`imovelN-fachada`, `-sala`,
`-quarto`, `-cozinha`, `-banheiro`), que é também o mínimo de fotos exigido para
publicar um imóvel no site. Sem esta pasta o comando cai para imagens sintéticas
e a demonstração continua rodando.
